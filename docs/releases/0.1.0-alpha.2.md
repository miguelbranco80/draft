## Why this release was superseded

A post-publication content audit found that both Linux archives installed
`libLLVM.so.22.1` and `libclang-cpp.so.22.1` as relative symbolic links without
including their terminal files. The links originally reached from Ubuntu's
versioned LLVM directory into its architecture-specific system library
directory; after relocation into the archive, they were broken.

The release smoke produced a false success because the hosted runners still
had the matching system LLVM packages installed. Their ELF loaders satisfied
the required SONAMEs from the host after the private links failed. Checksums
therefore prove that the downloaded assets match what GitHub published, but do
not make the two Linux archives self-contained.

The GitHub release notes were marked **Superseded: do not use this release** as
soon as the defect was confirmed. The immutable tag and this record remain for
an honest history. The following release installs complete LLVM link chains and
rejects every broken link before executing any distribution binary.

The macOS and Windows archives passed their native checks, but Draft releases
are qualified as one four-target set. The incomplete Linux runtime closure
therefore invalidates `0.1.0-alpha.2` as a whole.
