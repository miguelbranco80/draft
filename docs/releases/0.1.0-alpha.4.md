# Draft 0.1.0-alpha.4 qualification

Status: current published GitHub prerelease.

The immutable `v0.1.0-alpha.4` tag names source commit
`9e4ac9b89d08d3cf3f7a89363b3a422965831280`. GitHub published
[Draft 0.1.0-alpha.4](https://github.com/miguelbranco80/draft/releases/tag/v0.1.0-alpha.4)
on 2026-07-28 at 08:45:12 UTC.

## Native qualification

Pre-tag CI run
[30341957627](https://github.com/miguelbranco80/draft/actions/runs/30341957627)
passed on every maintained native host:

- macOS ARM64 completed the warning-clean bootstrap and full CTest suite;
- Linux ARM64 completed the warning-clean bootstrap and full CTest suite;
- Linux x86-64 completed the full suite under ASan and UBSan; and
- Windows x86-64 built the MSVC bootstrap, exercised native Draft PE/COFF and
  C interoperation, then qualified an isolated installed distribution.

The common distribution smoke invoked `draftc target`, `check`, and `build`
without `--target` on all four hosts. Each installed compiler reported and used
the profile matching its native host.

Tag-triggered release run
[30343028074](https://github.com/miguelbranco80/draft/actions/runs/30343028074)
rebuilt Release binaries on all four hosts. Each job verified the binary
version against the tag, built its native archive, extracted that archive into
a fresh directory, reran the installed-distribution smoke, and uploaded only
the qualified result. The publisher ran after all four jobs succeeded.

After publication, all five public assets were downloaded into a new temporary
directory. The published `SHA256SUMS` accepted every archive. Both Linux
archives were extracted and scanned recursively with symbolic-link following
enabled; neither contained a broken link. Their `libLLVM.so.22.1` and
`libclang-cpp.so.22.1` entries are ordinary ELF shared objects for the archive's
declared architecture, rather than links into the build host.

Finally, the downloaded macOS archive independently passed the same common
distribution smoke used in the workflow. Its installed `draftc` selected
AArch64 macOS without `--target`, checked, built, and ran the bundled hello
example, and its installed DraftIDE loaded the bundled compiler service and
completed a noninteractive frame.

The archives include the compiler, DraftIDE, matching private LLVM/Clang tools
and runtime libraries, readable `core` source, docs, examples, and the Draft
coding skill. Host platform SDK requirements and the alpha signing model are
documented in [Building and releasing Draft](../operations/releases.md).
