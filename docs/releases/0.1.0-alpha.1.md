# Draft 0.1.0-alpha.1 qualification

Status: locally qualified release candidate; tag publication not yet claimed.

This record covers source commit
`9a2929d02ec9c45ef6ca6a7d9d0cda4a25697d36`. The record itself is a later
documentation-only change. It does not alter the qualified compiler bytes.

## Local native qualification

The candidate was configured from a fresh build directory on 2026-07-27 with:

- macOS 26.5.2 (`25F84`) on AArch64;
- Apple Clang 21.0.0 as the C++20 bootstrap compiler;
- LLVM 22.1.8 from the explicit Homebrew LLVM 22 CMake package;
- CMake 4.3.0;
- `CMAKE_BUILD_TYPE=Release`;
- warnings as errors; and
- bootstrap sanitizers disabled.

Both `draftc --version` and `draftide --version` reported release
`0.1.0-alpha.1`, the exact qualified source commit, LLVM 22.1.8, the same
embedded core identity, and all four implemented target selectors. The complete
CTest run passed 98 of 98 tests in 33.73 seconds. That run included native
determinism and backend parity, C client integration, classified examples,
Draft tests and benchmarks, provider-free agent fixtures, DraftIDE/compiler-
service integration, and the isolated installed-distribution smoke.

## Archive qualification

CPack produced
`draft-0.1.0-alpha.1-aarch64-macos.tar.xz` from the same install manifest. The
exact local artifact was 63,392,692 bytes with SHA-256:

```text
fe02e259131b28a0d5a63f8983a0ab94b785bad5b0791b3484fed2620474e735
```

The archive expanded to approximately 333 MiB. Its private Clang resource tree
contained compiler-rt libraries but no unused general-purpose C builtin-header
set. After extraction into a new directory:

- `draftc` and `draftide` both reported `toolchain: bundled`;
- `draftc` checked, built, and launched the installed `examples/hello` package;
- DraftIDE loaded its installed sibling compiler service and completed its
  noninteractive smoke;
- neither binary needed a checkout, Homebrew LLVM path, or loader environment
  override; and
- strict recursive code-signature verification passed for both macOS
  executables after loader-path fixup and ad-hoc signing.

The tag-triggered workflow requires equivalent native qualification and an
extracted-archive smoke on AArch64 Linux, x86-64 Linux, and x86-64 Windows
before it can publish. This local record does not claim those hosted runs or a
GitHub release; their results must be added only after the workflow completes.
